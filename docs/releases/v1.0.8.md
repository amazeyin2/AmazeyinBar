# AmazeyinBar v1.0.8

本次更新让日历更适合日常安排：在日期上右键即可添加日程，未来的重要日期也更容易一眼找到。

## 新功能

- 右键月历日期选择“添加日程”，可创建定时或全天事件，并写入系统默认日历。
- 今天之后的法定节假日与有系统日程的日期显示小红点。

## 改进

- Sub2API Admin API Key 使用新的钥匙串服务名 `com.amazeyin.tools.bar`；旧密钥读取时会尝试迁移，无需主动重新导入。

添加和查看日程需要允许 AmazeyinBar 访问 macOS 日历。钥匙串服务名变更不等于更换 App 的 Bundle ID；首次读取旧条目时，macOS 仍可能要求授权。
